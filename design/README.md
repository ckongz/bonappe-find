# Design assets

`tokens.css` mirrors the application palette. The project uses Georgia and Arial/Lato fallbacks; no unlicensed Black Mango font is distributed.

The original SVG fork/magnifier icon and eight food/table drawings are in `client/public/`. These are illustrations, not genuine restaurant photographs. Replace them with images you have permission to use if the team wants real photography.

`mockups/social-01.svg` through `social-10.svg` are editable square social mockups. `social-copy.json` preserves the supplied captions, visual directions and hashtags. `email-*.html` are browser-viewable email design mockups, not automatically sent campaigns. Replace local links and example addresses before real use.

These assets can be imported or recreated in Figma. A real Figma file/prototype has not been created; Abygale and Ayenne should add the reviewed link to `docs/figma-links.md`.
