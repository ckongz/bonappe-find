# Suggest Restaurant update

- Responsive customer form with grouped fields, required-field feedback, URL validation, photo upload and preview.
- Separate suggestion history with search, status filters, timestamps and counts.
- Admin suggestion review uses the dashboard navigation; includes approval, publication and rejection reasons.
- Refresh preserves unfinished review edits and updates decisions and counts.

Verified: production client build; browser flows for validation, upload, submission, approval/publication, rejection, customer refresh, filters and mobile overflow. No browser JavaScript errors in these flows.
